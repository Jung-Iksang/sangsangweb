`npm run fetch-paperlogy` (scripts/fetch-paperlogy.mjs) 가 받아 만든 서브셋(`Paperlogy-{400..800}.subset.woff2`)과
`paperlogy.css` 를 `src/app/layout.tsx` 에서 연결한다. 사이트 전체 글꼴은 이것 하나 — 서브셋에 없는 글자는 Pretendard 로 폴백.
